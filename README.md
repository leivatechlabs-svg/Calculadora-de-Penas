# Calculadora de Penas HN

Aplicación web/PWA de apoyo para cálculos jurídicos basados en el Código Penal de Honduras.

**Titular:** Eber Noel Leiva Orellana  
**Copyright:** © 2026 Eber Noel Leiva Orellana. Todos los derechos reservados.

## Estado
La aplicación pública ofrece actualmente herramientas de cálculo jurídico. La arquitectura comercial prevista contempla acceso gratuito y un futuro plan Profesional/Premium con autenticación, historial, informes y administración.

## Uso jurídico
Los resultados son orientativos. Debe verificarse la legislación vigente y las reformas aplicables antes de utilizar un resultado con fines profesionales.
